# Common Jenkins Issues and Solutions for DevOps Engineers

Jenkins issues are very common in DevOps projects.
A DevOps engineer should know:

* How to identify the issue
* Root cause
* Troubleshooting commands
* Solution steps

---

# 1. Jenkins Service Not Starting

## Error

```text id="8j6cfu"
Jenkins failed to start
```

---

## Possible Causes

* Java not installed
* Port already in use
* Low memory
* Corrupted plugin
* Wrong configuration

---

## Troubleshooting Commands

## Check Jenkins Status

```bash id="k83wwr"
sudo systemctl status jenkins
```

## View Logs

```bash id="gopq2r"
sudo journalctl -u jenkins -f
```

## Check Java

```bash id="q70je0"
java -version
```

## Check Port Usage

```bash id="axjjsl"
sudo netstat -tulnp | grep 8080
```

---

## Solution

### Install Java

```bash id="wft0ru"
sudo apt install openjdk-17-jdk -y
```

### Restart Jenkins

```bash id="hmqx11"
sudo systemctl restart jenkins
```

### Change Jenkins Port

Edit:

```bash id="tfud8l"
sudo nano /etc/default/jenkins
```

Change:

```text id="eh43du"
HTTP_PORT=9090
```

# 8. Jenkins Pipeline Syntax Error

## Error

```text id="bjlwmz"
WorkflowScript: Expected a step
```

---

## Example Wrong Syntax

```groovy id="5c4i5e"
pipeline {
agent any
stages {
stage('Build') {
steps
sh 'echo Hello'
}
}
}
```

---

## Correct Syntax

```groovy id="opx34y"
pipeline {
    agent any

    stages {
        stage('Build') {
            steps {
                sh 'echo Hello'
            }
        }
    }
}
```

---

# 9. Docker Permission Denied in Jenkins

## Error

```text id="7u7u3y"
permission denied while trying to connect to Docker daemon socket
```

---

## Cause

Jenkins user not added to Docker group.

---

## Solution

## Add Jenkins to Docker Group

```bash id="g6or4k"
sudo usermod -aG docker jenkins
```

---

## Restart Jenkins

```bash id="d5cv4i"
sudo systemctl restart jenkins
```

Issue Occurred
      ↓
Check Jenkins Status
      ↓
Check Logs
      ↓
Identify Root Cause
      ↓

      ↓

      ↓
