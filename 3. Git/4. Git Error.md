# Git Errors and Solutions 

### 1. Non-Fast-Forward Error
- **Error:** `! [rejected] main -> main (non-fast-forward)`
- **Why This Happens:** Someone already pushed code. Remote repository has newer commits than your local repository.

### Solution
```bash id="n8jmkd"
git pull origin main
Then:
git push origin main
```

### 2. Merge Conflict Error
- **Error:** `CONFLICT (content): Merge conflict in app.py`
- **Why This Happens:** Two people modified same lines in same file.
### Solution
```bash id="hl7x2d"
# Step 1: Open File
You will see:
<<<<<<< HEAD
your code
=======
other person code
>>>>>>> branch-name

# Step 2: Edit Manually --> Keep correct code.

# Step 3:
git add .
git commit -m "Resolved merge conflict"
```
### 3. Permission Denied (Publickey)
- **Error:** `Permission denied (publickey)`
- **Why This Happens:** SSH key not added to GitHub.
### Solution
```bash id="t7bxgn"
# Generate SSH Key
ssh-keygen -t rsa -b 4096 -C "email@example.com"

#Start SSH Agent
eval "$(ssh-agent -s)"

# Add SSH Key
ssh-add ~/.ssh/id_rsa

# Copy Public Key
cat ~/.ssh/id_rsa.pub

Add it in GitHub:
* Settings
* SSH and GPG keys
```

### 4. Authentication Failed
- **Error:** `fatal: Authentication failed`
- **Why This Happens:** GitHub removed password authentication.
### Solution: Use Personal Access Token (PAT).
```bash id="z7hd7m"
# Update Remote URL
git remote set-url origin https://TOKEN@github.com/user/repo.git
```
### 5. Detached HEAD State
- **Error:** `You are in 'detached HEAD' state  `
- **Why This Happens:** You checked out a commit instead of branch.
### Solution
```bash id="lu5nvw"
git checkout main

# OR

# Create new branch:
git checkout -b new-branch
```
### 6. File Already Exists Error
- **Error:** `fatal: destination path already exists`
- **Why This Happens:** Folder already contains files.
### Solution
```bash id="w4j0bk"
# Clone into new folder:
git clone repo-url new-folder
```
### 7. Untracked Files Error
- **Error:** `Untracked files present`
- **Why This Happens:** Git found new files not added.
### Solution
```bash id="4swx5m"
git add . # or filename
```
### 8. Nothing to Commit
- **Error:** `nothing to commit, working tree clean`
- **Why This Happens:** No changes available.
### Solution
```bash id="lgv8qn"
# Modify file first. Then:
git add .
git commit -m "updated file"
```

### 9. Branch Already Exists
- **Error:** fatal: branch already exists
### Solution
```bash id="stgnq6"
# Switch branch:
git checkout branch-name

# OR delete old branch:
git branch -d branch-name
```
### 10. Cannot Delete Branch
- **Error:** `error: Cannot delete branch`
- **Why This Happens:** You are currently using that branch.
### Solution
```bash id="udx7nm"
# Switch branch:
git checkout main

# Then delete:
git branch -d feature-branch
```

### 11. Failed to Push Some Refs
- **Error:** `failed to push some refs`
- **Why This Happens:** Remote branch updated.
### Solution
```bash id="qkn2xg"
git pull --rebase origin main
git push origin main
```
### 12. Repository Not Found
- **Error:** `remote: `Repository not found`
- **Why This Happens:** Wrong repository URL, No permission

### Solution
```bash id="i0g1pa"
# Check URL:
git remote -v

# Update URL:
git remote set-url origin new-url
```

### 13. Git Ignore Not Working
- **Problem:** `.env` file still tracked.
### Solution
```bash id="fjlwm4"
# Remove Cached File
git rm --cached .env

# Add to .gitignore
.env

# Commit
git commit -m "Added gitignore"
```
### 14. Large File Error
- **Error:** file exceeds GitHub size limit
- **Why This Happens:** GitHub limit is 100 MB.
### Solution
```bash id="5j3w1q"
# Use Git LFS:
git lfs install

# Track files:
git lfs track "*.zip"
```

### 15. Conflict During Rebase
- **Error:** `CONFLICT during rebase`
### Solution
```bash id="1vrf2y"
# Fix file manually. Then:
git add .
git rebase --continue

# Cancel rebase:
git rebase --abort
```
### 16. Local Changes Would Be Overwritten
- **Error:** `Your local changes would be overwritten`
- **Why This Happens:** Pulling new code while local files modified.
### Solution

### 

```bash id="f5n1hj"
# Option 1: Commit Changes
git add .
git commit -m "saved changes"

# Option 2: Stash Chan or ges
git stash
git pull
git stash pop
```
### 17. Bad Object Error
- **Error:** `fatal: bad object`
- **Why This Happens:** Corrupted commit reference.
### Solution
```bash id="ovl8pa"
# Fetch again:
git fetch --all
```
### 18. Refusing to Merge Unrelated Histories
- **Error:** fatal: refusing to merge unrelated histories
- **Why This Happens:** Two repositories initialized separately.
### Solution

```bash id="a8x5mn"
git pull origin main --allow-unrelated-histories
```

### 19. Pathspec Error
- **Error:** `pathspec did not match any file`
- **Why This Happens:** Wrong filename or branch name.
### Solution
```bash id="qg5x8r"
# Check:
ls
git branch
```
### 20. Cannot Lock Ref
- **Error:** `cannot lock ref`
- **Why This Happens:** Git process interrupted.
### Solution
```bash id="h5t9pq"
# Delete lock file:
rm -f .git/index.lock
```
### 21. Remote Origin Already Exists
- **Error:** `remote origin already exists`
### Solution
```bash id="n6f4xz"
# Remove old remote:
git remote remove origin

# Add new remote:
git remote add origin repo-url
```
### 22. Pull Rebase Error
- **Error`:** `cannot pull with rebase
### Solution

```bash id="h4n2ys"
git rebase --abort
# Then:
git pull origin main
```
### 23. Stash Apply Conflict
- **Error:** Conflict after: `git stash apply`
### Solution
```bash id="jlwmq2"
# Resolve conflicts manually.Then:
git add .
git commit -m "Resolved stash conflict"
```

### 24. Accidental Commit to Main Branch
- **Problem:** Committed directly to main.
### Solution


```bash id="jlwmq3"
# Create branch:
git branch feature-backup

# Reset main:
git reset --hard HEAD~1
```
### 25. Accidentally Deleted File

### Solution



```bash id="jlwmq5"
# Restore file:
git restore filename

# Restore deleted commit:
git reflog

# Then:
git checkout commit-id
```
### 26. CI/CD Pipeline Failed After Git Push

**Common Reasons:**

* Wrong YAML syntax
* Jenkinsfile error
* Missing Dockerfile
* Terraform syntax issue

### Solution
```bash id="jlwmq8"
# Check:
git diff
```
Validate:

* YAML
* Terraform
* Docker build
* Jenkins syntax

### 27. GitHub Push Protection Error
- **Error:** Secret detected: `API_KEY detected`
### Solution
- Remove secret. Use:
* Kubernetes Secrets
* Vault
* AWS Secrets Manager

Never push:
* Passwords
* Tokens
* API keys

### 28. Invalid Username or Password
### Solution
Use PAT instead of password.

**Generate from:** GitHub → Settings → Developer Settings → Personal Access Tokens

### 29. Host Key Verification Failed
- **Error:** `Host key verification failed`
### Solution

```bash id="jlwmqb"
ssh-keyscan github.com >> ~/.ssh/known_hosts
```

### 30. Permission Denied While Cloning Private Repo
### Solution

Check:

* SSH key added
* Repository access granted
* Correct GitHub account

### Most Important Git Troubleshooting Commands

| Command         | Purpose                |
| --------------- | ---------------------- |
| git status      | Check repository state |
| git log         | View commit history    |
| git diff        | Compare changes        |
| git branch      | View branches          |
| git remote -v   | Check remote URLs      |
| git stash       | Save temporary changes |
| git reflog      | Recover lost commits   |
| git reset       | Undo changes           |
| git restore     | Restore files          |
| git fetch --all | Refresh repository     |

## Real DevOps Scenario Example

#### Scenario: Developer pushed broken Kubernetes YAML.
Pipeline failed in Jenkins.

#### DevOps Troubleshooting Steps
##### Check Latest Commit: `git log --oneline`
##### Compare Changes: `git diff HEAD~1`
##### Fix YAML: `vim deployment.yaml`
##### Commit Fix
```bash id="jlwmqf"
git add .
git commit -m "Fixed Kubernetes YAML issue"
```
##### Push Fix: `git push origin main`
