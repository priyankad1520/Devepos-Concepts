# Docker Errors and Solutions for DevOps Engineers

These are the most common Docker issues faced in real-time DevOps projects.

---

# 1. Docker Service Not Running

## Error

```text id="6hzdtv"
Cannot connect to the Docker daemon
```

OR

```text id="3s1ww9"
docker: Cannot connect to the Docker daemon at unix:///var/run/docker.sock
```

---

## Why This Happens

Docker service is stopped.

---

## Solution

## Check Docker Status

```bash id="7bf5n9"
sudo systemctl status docker
```

## Start Docker Service

```bash id="v1hh0f"
sudo systemctl start docker
```

## Enable Docker at Boot

```bash id="c7brzs"
sudo systemctl enable docker
```

---

# 2. Permission Denied Error

## Error

```text id="tr72j8"
permission denied while trying to connect to Docker daemon socket
```

---

## Why This Happens

User is not added to docker group.

---

## Solution

## Add User to Docker Group

```bash id="jw8w11"
sudo usermod -aG docker $USER
```

## Refresh Session

```bash id="owpzry"
newgrp docker
```

## Verify

```bash id="07wyyu"
docker ps
```

---

# 3. Port Already in Use

## Error

```text id="8u5f4z"
Bind for 0.0.0.0:80 failed: port is already allocated
```

---

## Why This Happens

Another application/container already uses the port.

---

## Solution

## Check Port Usage

```bash id="d2s8xg"
sudo netstat -tulnp
```

OR

```bash id="ab6flg"
sudo lsof -i :80
```

## Stop Existing Container

```bash id="tr8l2f"
docker ps
```

```bash id="s7bfrv"
docker stop container_id
```

## Run Container on Different Port

```bash id="jy0lq0"
docker run -d -p 8080:80 nginx
```

---

# 4. Container Exits Immediately

## Error

Container starts and stops automatically.

---

## Why This Happens

Main process inside container finished.

---

## Solution

## Check Logs

```bash id="7h4bzn"
docker logs container_id
```

## Run Interactive Mode

```bash id="s47r3w"
docker run -it ubuntu bash
```

---

# 5. Image Not Found

## Error

```text id="e11htz"
Unable to find image locally
```

OR

```text id="jq2eqp"
pull access denied
```

---

## Why This Happens

* Wrong image name
* Image not downloaded
* Private repository access issue

---

## Solution

## Pull Image

```bash id="5o97zi"
docker pull nginx
```

## Login to Docker Hub

```bash id="kigvif"
docker login
```

---

# 6. No Space Left on Device

## Error

```text id="9t7paz"
no space left on device
```

---

## Why This Happens

Unused containers/images consume disk space.

---

## Solution

## Check Disk Usage

```bash id="ehz2di"
df -h
```

## Remove Stopped Containers

```bash id="yyzbw7"
docker container prune
```

## Remove Unused Images

```bash id="b4um9j"
docker image prune -a
```

## Clean Entire Docker System

```bash id="m4v4cg"
docker system prune -a
```

---

# 7. Container Name Already Exists

## Error

```text id="1j8m53"
Conflict. The container name is already in use
```

---

## Why This Happens

Another container already uses the same name.

---

## Solution

## Check Containers

```bash id="tx2b8m"
docker ps -a
```

## Remove Old Container

```bash id="91vqcu"
docker rm container_name
```

OR use different name:

```bash id="jlwm9f"
docker run --name newcontainer nginx
```

---

# 8. Docker Build Failed

## Error

```text id="q1sk0j"
failed to solve with frontend dockerfile.v0
```

---

## Why This Happens

* Wrong Dockerfile syntax
* Missing file
* Package installation failed

---

## Solution

## Check Dockerfile Syntax

Example:

```dockerfile id="z1wzzl"
FROM ubuntu
RUN apt update
```

## Build Again

```bash id="lrmz7z"
docker build -t myapp .
```

---

# 9. Cannot Remove Image

## Error

```text id="8uk1zv"
image is being used by running container
```

---

## Why This Happens

Container uses the image.

---

## Solution

## Stop Container

```bash id="7t7nlj"
docker stop container_id
```

## Remove Container

```bash id="rjlwmv"
docker rm container_id
```

## Remove Image

```bash id="l8v8zb"
docker rmi image_id
```

# 10. Docker Pull Rate Limit

## Error

```text id="j5rzgm"
toomanyrequests: You have reached your pull rate limit
```

---

## Why This Happens

---

## Solution

* Google Container Registry
* Azure Container Registry

# 12. Network Connectivity Issue

## Error

Containers cannot communicate.

---

## Why This Happens

Containers are on different Docker networks.

---

## Solution

## Check Networks

```bash id="ktvfy0"
docker network ls
```

## Inspect Network

```bash id="qjlwmn"
docker network inspect bridge
```

## Create Network

```bash id="0wvq0h"
docker network create mynetwork
```

## Run Containers in Same Network

```bash id="n36k4n"
docker run -d --network=mynetwork nginx
```

---

# 13. Volume Mount Issue

## Error

Files not visible inside container.

---

## Why This Happens

Wrong mount path.

---

## Solution

## Correct Volume Mount

```bash id="xyi6xv"
docker run -v /host/path:/container/path nginx
```

## Check Mounts

```bash id="n7b7b0"
docker inspect container_id
```

---

# 14. DNS Resolution Failure

## Error

Container cannot access internet.

---

## Why This Happens

DNS issue inside Docker.

---

## Solution

## Restart Docker

```bash id="8yv3bt"
sudo systemctl restart docker
```

## Add DNS Manually

```bash id="x0vt7e"
docker run --dns 8.8.8.8 ubuntu
```

# 17. CrashLoop Type Issue

## Error

Container continuously restarting.

---

## Why This Happens

Application crash inside container.

---

## Solution

## Check Restart Count

```bash id="6mjlwm"
docker ps
```

## View Logs

```bash id="k7e5lx"
docker logs container_id
```

## Disable Restart Policy

```bash id="4xk3jc"
docker update --restart=no container_id
```

---

# 18. SSL/TLS Certificate Error

## Error

```text id="z4f6s5"
x509 certificate signed by unknown authority
```

---

## Why This Happens

Invalid/self-signed certificate.

---

## Solution

## Restart Docker

```bash id="ibv6ur"
sudo systemctl restart docker
```

## Add Trusted Certificate

Usually done in:

```text id="uzkxwp"
/etc/docker/certs.d/
```

---

---

## Why This Happens

High CPU/memory usage.

---

## Solution

## Monitor Usage

```bash id="e4y1a6"
docker stats
```

## Stop Unused Containers

```bash id="a6cm6o"
docker stop container_id
```

## Solution

## Restart Docker

# Important Troubleshooting Commands

| Command           | Purpose                  |
| ----------------- | ------------------------ |
| docker logs       | Check application logs   |
| docker ps         | Check running containers |
| docker inspect    | Detailed container info  |
| docker stats      | Resource monitoring      |
| docker exec       | Access container         |
| docker network ls | View networks            |
| docker volume ls  | View volumes             |
| docker system df  | Docker disk usage        |

```text id="x1jlwm"

       ↓

       ↓

       ↓
Check Resource Usage
       ↓

       ↓

       ↓
```
