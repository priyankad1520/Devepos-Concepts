# Common Terraform Issues/Errors and Their Solutions

Terraform errors are very common in DevOps projects because Terraform works with:

* Cloud providers
* APIs
* State files
* Networking
* IAM permissions

---

# 1. Terraform Init Errors

# Error: Provider Plugin Not Found

```text id="0nywy8"
Error: Failed to install provider
```

## Why It Happens

* Internet issue
* Wrong provider name
* Provider version issue

## Solution

```bash id="41zl39"
terraform init
```

## Reconfigure Initialization

```bash id="6ag2dr"
terraform init -reconfigure
```

## Delete Old Cache

```bash id="9h9c2l"
rm -rf .terraform
terraform init
```

---

# 2. Syntax Errors

# Error

```text id="i3lsjv"
Error: Invalid expression
```

OR

```text id="rlb5mj"
Error: Missing required argument
```

## Why It Happens

* Missing brackets
* Wrong indentation
* Wrong variable name

## Solution

```bash id="p9nxwu"
terraform validate
```

## Example Wrong Code

```hcl id="jz1bvp"
resource "aws_instance" "server" {
 ami = "ami-123"
 instance_type = 
}
```

## Correct Code

```hcl id="y6abdk"
resource "aws_instance" "server" {
 ami           = "ami-123"
 instance_type = "t2.micro"
}
```

# 3. Authentication Errors

# Error

```text id="82mr4w"
Error: No valid credential sources found
```

## Why It Happens

Terraform cannot access cloud account.

---

## AWS Solution

### Configure AWS CLI

```bash id="m7yc9w"
aws configure
```

### Check Credentials

```bash id="drxv08"
cat ~/.aws/credentials
```

---

## Azure Solution

```bash id="lf4j5t"
az login
```

---

## GCP Solution

```bash id="6hcrll"
gcloud auth application-default login
```

# 4. Access Denied Errors

# Error

```text id="yv6zrf"
AccessDenied
```

OR

```text id="9bj7e7"
UnauthorizedOperation
```

## Why It Happens

IAM user/role lacks permissions.

## Solution

Check:

* IAM policies
* Cloud permissions
* Role attachment

### Example AWS Permissions Needed

* EC2FullAccess
* S3FullAccess
* VPC permissions

---

# 5. State Lock Error

# Error

```text id="w5b35u"
Error acquiring the state lock
```

## Why It Happens

Another user/process is using Terraform state.

## Solution

### Force Unlock

```bash id="d1vaf5"
terraform force-unlock LOCK_ID
```

### Best Practice

Use remote backend:

* S3 + DynamoDB
* Azure Blob Locking

# 9. Dependency Errors

# Error

```text id="w0c37m"
DependencyViolation
```

## Why It Happens

Terraform tries deleting resource still in use.

Example:

* Security group attached to EC2
* Subnet attached to VPC

## Solution

Delete dependent resources first.

# 11. Variable Errors

# 19. Terraform Drift

# What is Drift?

Infrastructure changed manually outside Terraform.

Example:

* Someone manually deleted EC2
* Security group changed manually

---

## Detect Drift

```bash id="1g7jku"
terraform plan
```

## Fix Drift

```bash id="o5g5y4"
terraform apply
```

# 22. Sensitive Data Exposure

# Problem

Secrets visible in:

* State files
* Logs

## Solution

### Use Sensitive Variables

```hcl id="s9wjlwm"
variable "password" {
  sensitive = true
}
```

### Use Secret Tools

* HashiCorp Vault
* AWS Secrets Manager
* Azure Key Vault

# Terraform Troubleshooting Commands

| Command              | Purpose        |
| -------------------- | -------------- |
| terraform validate   | Check syntax   |
| terraform fmt        | Format code    |
| terraform plan       | Detect changes |
| terraform show       | Show state     |
| terraform state list | List resources |
| terraform refresh    | Sync state     |
| TF_LOG=DEBUG         | Debug logs     |
| terraform providers  | Show providers |

Error Occurs

      ↓

      ↓

# Most Common Issues in Companies

| Issue             | Common Reason        |
| ----------------- | -------------------- |
| State Lock        | Multiple users       |
| IAM Access Denied | Missing permissions  |
| Drift             | Manual cloud changes |
| Backend Errors    | S3/DynamoDB issue    |
| Variable Missing  | Wrong tfvars         |
| Dependency Error  | Wrong resource order |
| Timeout           | Slow cloud resource  |
| Module Error      | Wrong source path    |

---

# Best Practices to Avoid Terraform Errors

| Best Practice          | Why                |
| ---------------------- | ------------------ |
| Use Remote Backend     | Team collaboration |
| Use State Locking      | Prevent corruption |
| Run terraform plan     | Preview changes    |
| Use Modules            | Reusable code      |
| Store Secrets Securely | Security           |
| Use Git                | Version control    |
| Use CI/CD              | Automation         |
| Avoid Manual Changes   | Prevent drift      |
