# Terraform Commands Step-by-Step Process for a DevOps Engineer

Terraform is an Infrastructure as Code (IaC) tool created by HashiCorp.

DevOps engineers use Terraform to:

* Create cloud infrastructure
* Automate server provisioning
* Manage AWS, Azure, GCP resources
* Version control infrastructure
* Build reusable infrastructure modules

---

# 1. Install Terraform

## Check Terraform Version

```bash
terraform version
```

## Install Terraform (Ubuntu/Linux)

### Update Packages

```bash
sudo apt update
```

### Install Required Packages

```bash
sudo apt install -y gnupg software-properties-common curl
```

### Add HashiCorp GPG Key

```bash
curl -fsSL https://apt.releases.hashicorp.com/gpg | sudo apt-key add -
```

### Add Repository

```bash
sudo apt-add-repository "deb https://apt.releases.hashicorp.com $(lsb_release -cs) main"
```

### Install Terraform

```bash
sudo apt install terraform -y
```

---

# 2. Verify Installation

```bash
terraform version
```

### What Happens?

Checks installed Terraform version.

---

# 3. Create Terraform Project

## Create Folder

```bash
mkdir terraform-project
```

## Move Into Folder

```bash
cd terraform-project
```

---

# 4. Create Terraform File

## Create Main File

```bash
touch main.tf
```

### Why `.tf` File?

Terraform configuration files use `.tf` extension.

---

# 5. Write Basic Terraform Code

Example AWS EC2 Instance:

```hcl
provider "aws" {
  region = "us-east-1"
}

resource "aws_instance" "myserver" {
  ami           = "ami-12345678"
  instance_type = "t2.micro"
}
```

---

# 6. Initialize Terraform

```bash
terraform init
```

### What Happens?

* Downloads provider plugins
* Creates `.terraform` directory
* Initializes working directory

### Important

Always run:

```bash
terraform init
```

after:

* New project
* Provider changes
* Module changes

---

# 7. Validate Terraform Code

```bash
terraform validate
```

### Why We Use This

Checks syntax errors.

---

# 8. Format Terraform Code

```bash
terraform fmt
```

### Why We Use This

Automatically formats Terraform files.

---

# 9. Preview Infrastructure Changes

```bash
terraform plan
```

### What Happens?

Shows:

* What resources will be created
* Modified
* Deleted

### Very Important

DevOps engineers run:

```bash
terraform plan
```

before applying changes.

---

# 10. Apply Infrastructure

```bash
terraform apply
```

## Auto Approve

```bash
terraform apply -auto-approve
```

### What Happens?

Creates infrastructure in cloud.

---

# 11. Check Terraform State

```bash
terraform show
```

### Why We Use This

Displays current infrastructure state.

---

# 12. List Terraform Resources

```bash
terraform state list
```

### Example Output

```text
aws_instance.myserver
```

---

# 13. Destroy Infrastructure

```bash
terraform destroy
```

## Auto Approve

```bash
terraform destroy -auto-approve
```

### What Happens?

Deletes all infrastructure created by Terraform.

---


## Create Variables File

## Example Variable

```hcl

  default = "t2.micro"

```

## Create tfvars File

# 22. Refresh Terraform State

```bash
terraform refresh
```

### Why We Use This

Updates state file with real infrastructure.

---

# 23. Import Existing Resources

```bash
terraform import aws_instance.myserver i-123456789
```

### Why We Use This

Import manually created resources into Terraform.

---

# 24. Target Specific Resource

```bash
terraform apply -target=aws_instance.myserver
```

### Why We Use This

Apply changes only to one resource.

---

# 25. Terraform Graph

```bash
terraform graph
```

### Why We Use This

Shows dependency graph.

---

# 26. Terraform State Commands

## Pull State

```bash
terraform state pull
```

## Remove Resource From State

```bash
terraform state rm aws_instance.myserver
```

## Move State

```bash
terraform state mv old_resource new_resource
```

---

# 27. Terraform Taint

## Mark Resource for Recreation

```bash

```

### Untaint

```bash
terraform untaint aws_instance.myserver
```

# Common Terraform Errors and Solutions

# 1. Provider Not Found

## Error

```text
provider not found
```

## Solution

```bash
terraform init
```

---

# 2. Syntax Error

## Solution

```bash
terraform validate
```

---

# 3. State Lock Error

## Solution

```bash
terraform force-unlock LOCK_ID
```

---

# 4. Resource Already Exists

## Solution

Use:

```bash
terraform import
```

---

# 5. Access Denied

## Solution

Check:

* AWS credentials
* IAM permissions
