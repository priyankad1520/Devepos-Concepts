# Common Argo CD Issues with Solutions (DevOps Real-Time Troubleshooting)

Argo CD troubleshooting is very important for DevOps engineers because deployments can fail due to:

* Kubernetes issues
* Git repository issues
* Authentication problems
* YAML mistakes
* Network issues

---

# 1. Application Status = OutOfSync

## Problem

Argo CD shows:

```text id="4b9of0"
OutOfSync
```

### Meaning

Git repository code and Kubernetes cluster state are different.

---

# How to Check

```bash id="1zhv0d"
argocd app get myapp
```

---

# Solution

## Manual Sync

```bash id="og79ae"
argocd app sync myapp
```

---

## Auto Sync Enable

```bash id="bxglgk"
argocd app set myapp --sync-policy automated
```

---

# Real Example

```text id="d5fvfw"
Developer updated deployment.yaml in GitHub
↓
Argo CD detected change
↓
Cluster not updated yet
↓
Status becomes OutOfSync
```

---

# 2. Sync Failed

## Problem

```text id="c91i3m"
Sync Failed
```

---

# Causes

* Wrong YAML syntax
* Missing namespace
* Invalid Kubernetes resource
* Image pull issue

---

# Check Error

```bash id="s4o8m6"
argocd app get myapp
```

---

## Describe Application

```bash id="vh3xlt"
kubectl describe application myapp -n argocd
```

---

# Solution

## Validate YAML

```bash id="ddn2bp"
kubectl apply -f deployment.yaml --dry-run=client
```

---

## Fix YAML Indentation

Wrong:

```yaml id="w9b5o6"
containers:
-image: nginx
```

Correct:

```yaml id="e3owuk"
containers:
  - image: nginx
```

---

# 3. ImagePullBackOff

## Problem

Pod cannot download Docker image.

---

# Check Pods

```bash id="d58rw5"
kubectl get pods
```

---

# Check Pod Details

```bash id="90eh1h"
kubectl describe pod pod-name
```

---

# Common Causes

| Cause            | Example                |
| ---------------- | ---------------------- |
| Wrong image name | nginxh                 |
| Private registry | Authentication missing |
| Network issue    | Docker Hub unreachable |

---

# Solution

## Fix Image Name

Wrong:

```yaml id="b1t9eq"
image: nginxx
```

Correct:

```yaml id="8vhj7x"
image: nginx
```

---

## Add Image Pull Secret

```bash id="jk9gj0"
kubectl create secret docker-registry regcred
```

---

| Missing environment variable | SECRET missing            |

---

# Solution

## Check Logs

```bash id="jjlwmn"
kubectl logs pod-name
```

---

## Check Environment Variables

```bash id="mblq8k"
kubectl describe pod pod-name
```

# 5. Repository Authentication Failed

## Problem

```text id="ag8n1u"
authentication required
```

---

# Cause

Argo CD cannot access GitHub repository.

---

# Solution

## Add Repository Again

```bash id="it1r7r"
argocd repo add https://github.com/user/repo.git \
--username myuser \
--password mytoken
```

---

# SSH Method

## Generate SSH Key

```bash id="r9kpc5"
ssh-keygen
```

---

## Add Repo Using SSH

```bash id="0t2nxb"
argocd repo add git@github.com:user/repo.git
```

---

# 7. Permission Denied (RBAC Issue)

## Problem

Argo CD cannot deploy resources.

---

# Check Error

```bash id="lfm3h0"
kubectl logs deployment/argocd-application-controller -n argocd
```

---

# Solution

## Check Cluster Role Binding

```bash id="r0vdu2"
kubectl get clusterrolebinding
```

---

## Give Admin Permission

```yaml id="xtph4h"
kind: ClusterRoleBinding
```

---

# Apply RBAC

```bash id="5jl8qo"
kubectl apply -f rbac.yaml
```

---

# 14. Resource Already Exists

## Error

```text id="b4h2tl"
resource already exists
```

---

# Cause

Manual resource already present in cluster.

---

# Solution

## Delete Existing Resource

```bash id="c7zyfq"
kubectl delete deployment myapp
```

---

## Re-Sync

```bash id="xngqjv"
argocd app sync myapp
```

# 15. Application Deleted Accidentally

## Restore Application

```bash id="sbtyqr"

```

OR apply YAML again.

# Real-Time DevOps Troubleshooting Flow

```text id="qvsy6g"
Application Failed
        ↓
Check Argo CD Status
        ↓
Check Kubernetes Pods
        ↓
Check Logs
        ↓
Identify Root Cause
        ↓
Fix YAML / Image / Config
        ↓
Sync Again
        ↓
Application Healthy
```

# Most Common Problems in Companies

| Issue                      | Mostly Happens Due To |
| -------------------------- | --------------------- |
| OutOfSync                  | Git changed           |
| CrashLoopBackOff           | App crash             |
| ImagePullBackOff           | Wrong image           |
| Sync Failed                | YAML errors           |
| Permission Denied          | RBAC                  |
| Degraded                   | Pod unhealthy         |
| Repo Authentication Failed | Git credentials       |
