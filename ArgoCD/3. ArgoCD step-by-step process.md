# Argo CD Commands Step-by-Step Process for DevOps Engineers

Argo CD is a GitOps tool used to deploy applications automatically into Kubernetes from Git repositories.

---

### What Argo CD Does

```text
GitHub Repository
        ↓
Argo CD Monitors Git Repo
        ↓
Detects Changes
        ↓
Deploys Automatically to Kubernetes
```

---

### 1. Install Argo CD
```bash
# Create Namespace
kubectl create namespace argocd

# Install Argo CD
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
```
##### Why We Use This
To Installs: Argo CD Server, Controller, Repo Server, Redis, UI components

### 2. Check Argo CD Pods

```bash
kubectl get pods -n argocd
```
```text
#  Example Output
argocd-server
argocd-application-controller
argocd-repo-server
argocd-redis
```

### 3. Check Argo CD Services

```bash
kubectl get svc -n argocd
```

### 4. Access Argo CD UI

## Port Forward

```bash
kubectl port-forward svc/argocd-server -n argocd 8080:443
# Access URL
https://localhost:8080
```
### 5. Get Default Admin Password

```bash
kubectl get secret argocd-initial-admin-secret -n argocd -o yaml

# Decode Password
kubectl get secret argocd-initial-admin-secret -n argocd -o jsonpath="{.data.password}" | base64 -d
```

### 6. Login to Argo CD CLI
```bash
# Install CLI
# Linux
curl -sSL -o argocd https://github.com/argoproj/argo-cd/releases/latest/download/argocd-linux-amd64

# Give Execute Permission
chmod +x argocd

# Move Binary
sudo mv argocd /usr/local/bin/

# Verify Installation
argocd version
```

### 7. Login Using CLI

```bash
argocd login localhost:8080
```

### 8. Add Kubernetes Cluster

```bash
# Check Current Cluster
kubectl config current-context

# Add Cluster
argocd cluster add <cluster-name>

# Example
argocd cluster add minikube
```
> Why We Use This: Registers Kubernetes cluster with Argo CD.

### 9. Create Application

```bash
argocd app create myapp \
--repo https://github.com/user/project.git \
--path kubernetes \
--dest-server https://kubernetes.default.svc \
--dest-namespace default
```
**Explanation**

| Option           | Purpose                |
| ---------------- | ---------------------- |
| --repo           | GitHub repository      |
| --path           | Kubernetes YAML folder |
| --dest-server    | Kubernetes cluster     |
| --dest-namespace | Deployment namespace   |

### 10. Sync Application

```bash
argocd app sync myapp
```
> Why We Use This: Deploys latest Git changes to Kubernetes.

### 11. Check Application Status

```bash
argocd app get myapp
```
### 12. List Applications

```bash
argocd app list
```
### 13. Delete Application

```bash
argocd app delete myapp
```
### 14. View Application Logs

```bash
kubectl logs -n argocd deployment/argocd-server
```

### 15. Refresh Application

```bash
argocd app refresh myapp
```

> Why We Use This: Forces Argo CD to check latest Git changes.

## 16. Enable Auto Sync

```bash
argocd app set myapp --sync-policy automated
```
> What Happens?. Whenever code changes in GitHub:  Argo CD detects changes. Then Automatically deploys to Kubernetes


### 17. Disable Auto Sync

```bash
argocd app unset myapp --sync-policy
```
### 18. Rollback Application

#

```bash
# View History
argocd app history myapp

# Rollback
argocd app rollback myapp 2
```
> Why We Use This: Rollback to previous stable version.

### 19. Delete Argo CD

```bash
kubectl delete namespace argocd
```

### Important kubectl Commands Used with Argo CD
```bash
# Check Pods
kubectl get pods -A

# Check Deployments
kubectl get deployments -A

# Check Services
kubectl get svc -A

# Describe Pod
kubectl describe pod pod-name -n argocd

# Check Logs
kubectl logs pod-name -n argocd
```
### Real-Time DevOps Workflow Using Argo CD

##### Step 1: Developer Pushes Code

```bash
git push origin main
```
##### Step 2: GitHub Repository Updated
Contains: Kubernetes YAML,  Helm Charts, Kustomize files

##### Step 3: Argo CD Detects Changes
Argo CD continuously watches Git repository.

##### Step 4: Sync Starts

```bash
argocd app sync myapp
# OR auto sync happens automatically.
```

##### Step 5: Kubernetes Deployment Updated

Pods restart with latest version.

## Common Argo CD Issues and Troubleshooting

### 1. Application OutOfSync
```bash
# Check Status
argocd app get myapp

# Fix
argocd app sync myapp
```
### 2. Pod CrashLoopBackOff
```bash
# Check Pods
kubectl get pods

# Check Logs
kubectl logs pod-name
```
### 3. Repo Authentication Failed
- **Cause:** Wrong Git credentials.
- **Fix:** Add repository again with credentials.

### 4. Permission Denied
```bash
# Check RBAC
kubectl get clusterrolebinding
```
### 5. Sync Failed
```bash
# Describe Application
kubectl describe application myapp -n argocd
```

# Argo CD Architecture

```text
GitHub Repository
        ↓
Repo Server
        ↓
Application Controller
        ↓
Kubernetes API Server
        ↓
Pods / Deployments / Services
```

---

### Argo CD Components
| Component              | Purpose        |
| ---------------------- | -------------- |
| API Server             | UI and API     |
| Repo Server            | Reads Git repo |
| Application Controller | Syncs apps     |
| Redis                  | Caching        |
| Dex                    | Authentication |

### Argo CD vs Jenkins
| Argo CD               | Jenkins               |
| --------------------- | --------------------- |
| Deployment Tool       | CI Tool               |
| GitOps                | Pipeline Automation   |
| Kubernetes Focused    | General Automation    |
| Pull-Based Deployment | Push-Based Deployment |

### Argo CD + DevOps Tools Integration

| Tool       | Usage              |
| ---------- | ------------------ |

| Kubernetes | Deployment target  |
